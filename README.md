# Pedidos UMADECAMPI

Site estático para lançamento de pedidos de camisetas por setor e congregação.

## Acesso inicial

### Administrador
- Login: `admin`
- Senha: `umadecampi2026`

### Setores
- Login: `setor01` até `setor21`
- Senha: `umade01` até `umade21`

## Observação

Esta versão salva os dados no navegador do dispositivo. Para uso oficial com vários usuários ao mesmo tempo, o próximo passo é integrar banco de dados online.
